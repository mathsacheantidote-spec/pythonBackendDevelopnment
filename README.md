# Python Backend Web Development Course (with Django) 🐍🌐

This repository contains my practice scripts, backend exercises, and full-stack web applications built while following the **Python Backend Web Development Course** (developed by CodeWithTomi / freeCodeCamp).

## 🚀 Projects Built
1. **Word Counter App** – A Django web app demonstrating GET vs. POST requests and dynamic template rendering.
2. **Full-Stack Blog Application** – A dynamic blog featuring database models, CRUD functionality via the Django Admin panel, and dynamic URL routing.
3. **Weather Detector App** – A real-time weather lookup tool integrating the OpenWeatherMap API and JSON data parsing.
4. **Realtime Chat Application** – A multi-room chat platform built with Django, AJAX, and asynchronous database polling without page reloads.
5. **RESTful Student API** – A token-authenticated API built using Django REST Framework (DRF) and model serializers.

## 📚 Course Syllabus & Topics Covered
- **Python Fundamentals:** Data structures (lists, tuples, dictionaries), loops, functions, file handling, error handling (`try/except`), and Object-Oriented Programming (classes & inheritance).
- **Django Core:** Virtual environments (`virtualenvwrapper`), project/app architecture, URL routing, views, and Jinja/Django Template Language.
- **Databases & Auth:** Django ORM models, SQLite & PostgreSQL integration, user registration/login/logout, CSRF protection, and admin panel management.
- **APIs with Django REST Framework:** Class-based `APIView`, serializers, token authentication, and endpoint testing with Postman.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Framework:** Django & Django REST Framework (DRF)
- **Database:** SQLite3 & PostgreSQL
- **Frontend & Tools:** HTML/CSS, AJAX (jQuery), Git, Postman
